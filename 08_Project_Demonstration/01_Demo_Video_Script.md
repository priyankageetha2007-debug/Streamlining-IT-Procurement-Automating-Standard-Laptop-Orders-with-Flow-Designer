# Phase 8 – Project Demonstration

## Demo Video Requirements
The SmartBridge instructions require a complete project demonstration video uploaded to Google Drive with public/anyone-with-link viewing enabled.

## Suggested Video Structure

### 1. Introduction
Say:
“Hello, this is our project titled Streamlining IT Procurement: Automating Standard Laptop Orders with Flow Designer.”

### 2. Purpose
Explain that the project automates creation and assignment of a configuration task for Standard Laptop service requests after approval.

### 3. Benefits
Explain:
- reduces manual intervention
- reduces configuration delays
- automatically assigns work to Hardware
- improves the procurement workflow

### 4. Live Execution
Screen-share and demonstrate:
1. ServiceNow home
2. Flow Designer
3. Standard laptop task flow
4. Service Catalog trigger
5. Create Catalog Task action
6. Field mappings
7. Activated flow
8. Standard Laptop catalog item
9. Order Now
10. Request Number
11. Approval
12. Requested Item
13. Catalog Tasks
14. Final Catalog Task with short description and Hardware assignment

### 5. Final Output
Show the generated Catalog Task and explain that it contains the required configuration information and assignment.

## Demo Closing
“Thank you. This demonstrates our automated Standard Laptop procurement workflow using ServiceNow Flow Designer.”
