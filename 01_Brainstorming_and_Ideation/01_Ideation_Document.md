# Phase 1 – Brainstorming & Ideation

## Project Title
Streamlining IT Procurement: Automating Standard Laptop Orders with Flow Designer

## Problem Identified
The current standard laptop procurement process has manual steps. Configuration requests may be delayed or overlooked, creating additional waiting time for users and manual overhead for the IT department.

## Proposed Idea
Use ServiceNow Flow Designer to automatically create a Catalog Task after approval of a Standard Laptop service request.

## Idea Flow
User → Standard Laptop Catalog Item → Request → Approval → Flow Designer → Catalog Task → Hardware Team → Laptop Configuration

## Expected Benefits
1. Faster task creation
2. Reduced manual intervention
3. Consistent task information
4. Automatic assignment to Hardware
5. Better resource utilisation
6. Reduced user waiting time

## Scope
The project focuses on the Standard Laptop service catalog process and automatic creation/assignment of the configuration task.

## Out of Scope
The source project document does not specify hardware purchasing, inventory integration, email notification design, or external procurement-system integration. These are therefore not included in the core implementation.
