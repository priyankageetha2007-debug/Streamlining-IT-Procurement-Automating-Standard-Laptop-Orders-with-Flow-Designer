# Phase 4 – Project Planning

## Milestones

| Milestone | Work |
|---|---|
| M1 | Create and activate Flow |
| M2 | Assign Flow to Standard Laptop catalog item |
| M3 | Place Standard Laptop order and validate Catalog Task |

## Suggested Work Breakdown

### M1 – Flow Creation
1. Open ServiceNow.
2. Open Flow Designer.
3. Create a Flow.
4. Configure Flow properties.
5. Add Service Catalog trigger.
6. Add Create Catalog Task action.
7. Map fields.
8. Save and activate.

### M2 – Flow Assignment
1. Open Maintain Items.
2. Open Standard Laptop.
3. Open Process Engine.
4. Remove remaining automations.
5. Add Standard Laptop Task flow.
6. Save.

### M3 – End-to-End Validation
1. Open Service Catalog.
2. Select Hardware.
3. Select Standard Laptop.
4. Click Order Now.
5. Open the Request Number.
6. Open Approvers.
7. Approve the request.
8. Open Requested Item.
9. Open Catalog Tasks.
10. Verify the generated task.

## Team Roles
For a 2–5 member student team, roles can be divided as:
- ServiceNow configuration
- Requirements/design
- Testing
- Documentation
- Demo/GitHub management

The actual team members should be entered after the team is formed.
